# Java 创建线程

## 1.继承Thread类
继承`Thread`类1：**`MyThread1.java`**
```java
public class MyThread1 extends Thread {
    @Override
    public void run() {
        System.out.println("Hello World!");
    }
}
```
继承`Thread`类2：**`MyThread2.java`**
```java
public class MyThread1 extends Thread {
    @Override
    public void run() {
        System.out.println("Hello World!");
    }
}
```
代码示范：
```java
public class Application {
    /**
     * 创建Java线程方式一：继承Thread类
     *  1.创建一个类MyThread，继承Thread；
     *  2.重写run()方法；
     *  3.创建子类MyThread对象，并调用对象的start()方法启动线程；
     *  【注】一定要调用对象的start()方法，不能直接调用run()方法；
     */
    public static void main(String[] args) {
        // 创建子类对象
        MyThread1 thread1 = new MyThread1();
        // 调用对象的start()方法启动线程
        thread1.start();

        // 创建子类对象
        MyThread2 thread2 = new MyThread2();
        // 调用对象的start()方法启动线程
        thread2.start();
    }
}
```
输出结果：
```java
Hello World!
Hi!
```

## 2.实现Runnable接口
实现`Runnable`接口类1：**`MyRunnable.java`**
```java
public class MyRunnable implements Runnable {
    @Override
    public void run() {
        // 线程需要执行的代码
        for (int i = 0; i < 5; i++) {
            System.out.println("Hello, world!");
        }
    }
}
```
代码示范：
```java
public class Application {
    /**
     * 创建Java线程方式二：实现Runnable接口
     *  1.创建一个类MyRunnable，实现Runnable接口
     *  2.重写run()方法；
     *  3.创建实现类MyRunnable对象；
     *  4.创建一个Thread对象，将实现类MyRunnable对象作为入参传递给Thread对象，并启动start()方法；
     */
    public static void main(String[] args) {
        // 创建实现类对象
        MyRunnable myRunnable = new MyRunnable();
        // 创建Thread对象，并将实现类作为参数传递给Thread
        Thread thread = new Thread(myRunnable);
        // 启动线程
        thread.start();
    }
}
```
输出结果：
```java
Hello, world!
Hello, world!
Hello, world!
Hello, world!
Hello, world!
```
## 3.利用Callable接口和Future接口
实现`Callable`接口类1：**`MyCallable.java`**
```java
public class MyCallable implements Callable<Integer> {
    @Override
    public Integer call() throws Exception {
        System.out.println(Thread.currentThread().getName() + " : " + "开始执行");
        // 求0~99的和
        int sum = 0;
        for (int i = 0; i < 100; i++) {
            sum += i;
        }
        System.out.println(Thread.currentThread().getName() + " : " + "执行结束");
        System.out.println(Thread.currentThread().getName() + " : " + "sum = " + sum);
        return sum;
    }
}
```
代码示范：
```java
public class Application {
    /**
     * 创建Java线程方式三：实现Callable接口
     *  1.创建一个类MyCallable，实现Callable接口
     *  2.重写call()方法；（有返回值，表示线程运行的结果）
     *  3.创建实现类MyCallable对象；（表示多线程要执行的任务，等价于实现Runnable接口的类）
     *  4.创建FutureTask对象；（管理多线程的运行的结果，要获取结果全靠Future对象，Future是接口，只能创建实现类FutureTask）
     *  5.创建一个Thread对象，将实现类FutureTask对象作为入参传递给Thread对象，并启动start()方法；
     */
    public static void main(String[] args) throws ExecutionException, InterruptedException {
        // 创建MyCallable对象
        MyCallable myCallable = new MyCallable();
        // 创建FutureTask对象
        FutureTask<Integer> futureTask = new FutureTask<>(myCallable);
        // 创建线程对象
        Thread thread = new Thread(futureTask);

        thread.start();
        // 获取多线程运行的结果
        System.out.println("线程运行的结果：" + futureTask.get());
    }
}
```
输出结果：
```java
Thread-0 : 开始执行
Thread-0 : 执行结束
Thread-0 : sum = 4950
线程运行的结果：4950
```
