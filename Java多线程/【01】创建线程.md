# Java 创建线程

## 1.继承Thread类
类1：**`MyThread1.java`**
```java
public class MyThread1 extends Thread {
    @Override
    public void run() {
        System.out.println("Hello World!");
    }
}
```
类2：**`MyThread2.java`**
```java
public class MyThread1 extends Thread {
    @Override
    public void run() {
        System.out.println("Hello World!");
    }
}
```
代码示范：
```java
public class Application {
    /**
     * 创建Java线程方式一：继承Thread类
     *  1.创建一个类MyThread，继承Thread；
     *  2.重写run()方法；
     *  3.创建子类MyThread对象，并调用对象的start()方法启动线程；
     *  【注】一定要调用对象的start()方法，不能直接调用run()方法；
     */
    public static void main(String[] args) {
        // 创建子类对象
        MyThread1 thread1 = new MyThread1();
        // 调用对象的start()方法启动线程
        thread1.start();

        // 创建子类对象
        MyThread2 thread2 = new MyThread2();
        // 调用对象的start()方法启动线程
        thread2.start();
    }
}
```
输出结果：
```java
Hello World!
Hi!
```
