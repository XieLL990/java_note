## 📝 题目描述

给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 **O(n)** 的算法解决此问题。

> **注意**：序列元素是数值上连续（相差 1），不要求它们在原数组中的位置相邻。

## 🧪 示例

**示例 1：**

```
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
```

**示例 2：**

```
输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
```

**示例 3：**

```
输入：nums = [1,0,1,2]
输出：3
```

## ⚠️ 提示（约束条件）

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## 🚀 核心难点

- 题目**硬性要求 O(n) 时间复杂度**，因此**不能使用排序**（排序最快 O(n·logn)）
- 需要借助 **哈希表 / 哈希集合** 的 O(1) 查找能力
